Machine Learning Enhancements to a VC2 Value Strategy

CS 4641/7641 Project Proposal Group 56

1. Introduction and Background

Value investing is one of the most well-documented strategies in empirical finance. Research by Eugene Fama and Kenneth French shows that valuation measures such as price-to-book help explain cross-sectional differences in expected returns [1]. Composite value approaches improve robustness by combining multiple metrics rather than relying on a single ratio. The Value Composite Two (VC2) approach uses PB, PE, PS, PCF, EV/EBITDA, and shareholder yield to identify undervalued securities.

Despite its strong historical performance, value investing often overstates results in practice. This is due to issues such as lookahead bias when aligning fundamentals with prices, instability across market regimes, and parameter sensitivity [2], [3]. Additionally, value traps—stocks that appear cheap but continue to decline—can reduce realized returns.

This project evaluates whether supervised and unsupervised machine learning methods can improve the robustness and risk-adjusted performance of a VC2 strategy implemented in Backtrader. The goal is to enhance returns while reducing bias and improving stability across varying market conditions.

Dataset. We use daily panel data for S&P 500 stocks from 2013–2024 (approximately 500 stocks over ~2,500 trading days). Each stock includes close price, RSI, PB, PE, PS, PCF, EV/EBITDA, and shareholder yield, with valuation ratios derived from structured fundamental data and aligned to daily prices.

The dataset exhibits both temporal and cross-sectional dependencies, meaning observations are related over time for each stock and across stocks at each point in time. Additional features, including short-term momentum and rolling volatility, are constructed from price data. This panel structure supports both supervised and unsupervised learning.

2. Problem Definition and Motivation

Problem. A standard VC2 strategy ranks stocks cross-sectionally and selects the lowest-valued names. However, it faces several practical limitations. It is vulnerable to value traps, where cheap stocks continue to underperform. Its effectiveness also varies across market regimes, as value strategies behave differently under changing volatility and macroeconomic conditions. Additionally, performance can depend on assumptions about when financial data becomes available. These issues reduce the reliability of backtests and limit real-world applicability.

Motivation. To obtain reliable results in financial machine learning, time-aware evaluation is essential. This project applies a walk-forward framework with machine learning models to filter stocks and adapt to regimes. The objective is to determine whether these methods can improve robustness compared to a traditional composite value strategy.

3. Methods

3.1 Baseline Strategy. We implement VC2 in Backtrader to simulate historical performance. Stocks are ranked relative to each other using percentile rankings based on valuation metrics. The most undervalued stocks are selected, and the top N are equally weighted in the portfolio. The portfolio is rebalanced every 28 trading days. Transaction costs and slippage are included to reflect realistic trading conditions.

3.2 Data Preprocessing. Data preprocessing is conducted using Python libraries such as pandas and numpy. Key steps include cross-sectional percentile ranking of valuation ratios, winsorization to reduce the impact of outliers, and time-alignment experiments (e.g., lagging fundamentals) to test sensitivity to reporting assumptions. Momentum and volatility features are also constructed from price data. These steps aim to reduce noise and mitigate lookahead bias.

3.3 Supervised Learning Methods. Two supervised classification models are implemented using libraries such as scikit-learn and XGBoost. Logistic Regression is a linear model used to predict whether a stock selected by VC2 will outperform the market over a specified horizon and provides an interpretable baseline. Gradient Boosting is a non-linear ensemble model capable of capturing interactions between valuation and technical features. Models are trained using time-series cross-validation (rolling windows) to prevent information leakage. The classifiers act as filters: VC2 generates candidate stocks, and the model selects those with the highest predicted probability of outperformance.

3.4 Unsupervised Learning Method. To address regime instability, we apply Principal Components Analysis (PCA) to market-state features such as return dispersion and volatility. The resulting components serve as indicators of market regimes and allow the strategy to adapt its behavior across different environments.

4. Potential Results and Evaluation

Evaluation Metrics. Trading metrics: CAGR, Sharpe ratio, Sortino ratio, maximum drawdown, turnover, and transaction-cost-adjusted returns. ML metrics: ROC-AUC, precision-recall AUC, and precision at top-K selections. Robustness metrics: rolling Sharpe ratio and performance across identified regimes.

Experimental Comparisons. We compare the baseline VC2 strategy, VC2 under alternative fundamental timing assumptions, VC2 with logistic regression filtering, VC2 with gradient boosting filtering, and VC2 with PCA-based regime adaptation.

We expect supervised models to reduce value traps and improve risk-adjusted returns, while PCA-based adjustments enhance stability across market regimes.

Sustainability and Ethical Considerations. The project addresses bias by testing timing assumptions and using time-aware validation. The selected models are computationally efficient and scalable. Transaction costs and turnover are included to ensure realistic and economically meaningful results.
