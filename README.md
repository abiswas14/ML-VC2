# MLVC2

Georgia Tech machine learning project repository for evaluating a VC2-style value/momentum equity strategy and several machine-learning extensions.

The project uses per-ticker historical factor data, builds VC2-ranked candidate sets, and compares the baseline strategy against logistic regression, gradient boosting, and market-regime analysis experiments.

## Quick Start

Install the Python dependencies:

```bash
pip install numpy pandas matplotlib scikit-learn backtrader
```

Run the main experiments from the repository root:

```bash
python vc2strategy.py
python vc2_logistic_regression.py
python vc2_gradient_boosting.py
python vc2_regime_clustering.py
```

See `DEPENDENCIES.md` for dependency notes.

## Repository Layout

### Source Files

| File | Purpose |
|---|---|
| `vc2strategy.py` | Backtrader implementation of the baseline VC2 portfolio strategy. It ranks stocks by valuation factors, applies RSI as a secondary sort, rebalances every 28 bars, and reports portfolio statistics. |
| `vc2_logistic_regression.py` | End-to-end logistic regression experiment. It preprocesses ticker data, builds lagged features, trains on pre-2020 data, evaluates test-period classification metrics, and compares baseline VC2 vs model-filtered portfolios. |
| `vc2_gradient_boosting.py` | Gradient boosting version of the ML filter experiment. It mirrors the logistic regression data pipeline and compares baseline VC2 against a HistGradientBoostingClassifier-filtered portfolio. |
| `vc2_regime_clustering.py` | Market-regime clustering experiment. It builds market-level features, fits KMeans regimes on the training period, and evaluates VC2 performance by test-period regime. |
| `index.html` | Course/project webpage or report-style HTML summary. |

### Data

| Path | Purpose |
|---|---|
| `data/*.csv` | Historical per-ticker stock datasets. There are 582 ticker CSV files in this repository. |
| `data/A.csv`, `data/AAPL.csv`, `data/SPY.csv`, etc. | Individual ticker files. Each file is named by ticker symbol and uses the shared schema below. |

Expected CSV schema:

```text
date,price,rsi,pb_ratio,pe_ratio,ps_ratio,pcf_ratio,ev_ebitda,shareholder_yield
```

Notes:

- `date` is parsed as the time index for time-series processing.
- `price` is used for returns and Backtrader OHLC proxy fields.
- `rsi` is used as the secondary VC2 selection signal.
- The valuation and yield fields are used to compute cross-sectional VC2 ranks.

## Experiment Summary

The baseline VC2 workflow is:

1. Load ticker-level CSV files from `data/`.
2. Rank stocks cross-sectionally using value factors, where lower valuation ratios are better and higher shareholder yield is better.
3. Keep the cheapest VC2 candidates.
4. Sort candidates by RSI.
5. Hold the top selected names in an equal-weight portfolio and rebalance periodically.

The ML experiments reuse the VC2 candidate set, add lagged factor ranks and price-derived features, then evaluate whether a classifier improves the selected portfolio during the test period.

The regime experiment does not replace the selection model. It clusters market environments and measures when the baseline VC2 strategy performs better or worse.
